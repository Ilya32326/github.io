Шифровальня

От шифра Цезаря до AES-256 — шифруйте и расшифровывайте текст прямо в браузере, без отправки на сервер.

Древнеримский шифр простой замены: каждая буква сдвигается по алфавиту на фиксированное число позиций.

Целое число, например 3 — каждая буква сдвигается на 3 позиции вперёд.

Все вычисления происходят локально в вашем браузере, с помощью Web Crypto API для AES.
